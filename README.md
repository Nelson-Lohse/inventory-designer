# Inventory Designer

A personal tool for planning restaurant back-of-house storage layouts —
dry storage, walk-ins, and shelving — as a 2D floorplan before physically
moving anything.

Status: **scaffold only, v1 not yet implemented.** See [ARCHITECTURE.md](./ARCHITECTURE.md)
for the tech stack, data model, folder structure, and roadmap.

## Getting started (once implementation begins)

```bash
npm install
npm run dev
```

Dependency versions in `package.json` are placeholders — resolve to actual
latest stable versions when dependencies are first installed.
